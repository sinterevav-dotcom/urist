# Бизнес-юрист — Telegram Mini App

Бесплатный юрист и налоговый помощник для ИП и ООО (Россия).

- **Справочник** — 8 статей со ссылками на статьи законов, поиск, категории
- **Документы** — договор оказания услуг, претензия о долге, акт: анкета → Word-файл
- **Налоги** — калькуляторы УСН 6% / 15%, НПД, взносы ИП; календарь сроков с переносом с выходных
- **Бот** — кнопка открытия приложения, документы в чат, напоминания о сроках за 3 дня и в день срока

Стоимость работы: **0 ₽**. Без ИИ, без платных API, без серверов с персональными данными:
настройки пользователя хранятся на его устройстве и в Telegram CloudStorage.

```
/      мини-приложение (корень репозитория): чистый HTML/CSS/JS, без сборки и зависимостей
bot/   бот на Cloudflare Workers (бесплатный тариф)
```

## Запуск за 0 ₽ — пошагово

### 1. Создать бота
1. В Telegram откройте @BotFather → `/newbot` → придумайте имя и юзернейм.
2. Сохраните токен вида `123456:ABC...` — никому его не показывайте.

### 2. Опубликовать мини-приложение (GitHub Pages)
1. Создайте репозиторий на GitHub, например `biz-lawyer`, и загрузите туда содержимое папки `web/`.
2. Settings → Pages → Source: `Deploy from a branch`, ветка `main`, папка `/ (root)`.
3. Через минуту приложение будет доступно по адресу `https://ВАШ-ЛОГИН.github.io/biz-lawyer/`.

Альтернатива — Cloudflare Pages: Workers & Pages → Create → Pages → загрузить папку `web/`.

### 3. Запустить бота (Cloudflare Workers)
Нужен бесплатный аккаунт Cloudflare и Node.js на компьютере.

```bash
cd bot
npm install
npx wrangler login
npx wrangler kv namespace create USERS      # скопируйте id в wrangler.toml
# в wrangler.toml укажите WEBAPP_URL — адрес из шага 2
npx wrangler secret put BOT_TOKEN           # токен от BotFather
npx wrangler secret put WEBHOOK_SECRET      # любая длинная случайная строка
npx wrangler secret put SETUP_KEY           # ещё одна случайная строка
npx wrangler deploy
```

После деплоя откройте в браузере один раз:
`https://biz-lawyer-bot.ВАШ-АККАУНТ.workers.dev/setup?key=ВАШ_SETUP_KEY`
Это подключит вебхук, кнопку «Открыть» в меню бота и команды.

### 4. Связать приложение с ботом
В `js/config.js` впишите адрес воркера:
```js
export const API_URL = 'https://biz-lawyer-bot.ВАШ-АККАУНТ.workers.dev';
```
и обновите файлы на GitHub. Готово: документы приходят в чат, напоминания работают.

В @BotFather можно также сделать Mini App основной: `/mybots` → бот → Bot Settings → Configure Mini App.

## Проверка
```bash
npm test            # расчёты налогов, календарь, генерация Word, справочник
cd bot && npm test     # подпись Telegram, вебхук, документы, напоминания
```
Локально: `python3 -m http.server 8080` → http://localhost:8080 (без Telegram документы скачиваются).

## Что обновлять раз в год
Всё в одном месте — `js/lib/tax.js`:
- `RATES`: взносы ИП, лимит 1%, лимиты УСН и НДС;
- `HOLIDAYS`: нерабочие дни по производственному календарю.

Статьи — `js/data/articles.js` (поле `checked` — дата проверки), шаблоны — `js/data/templates.js`.
Перед публичным запуском шаблоны документов стоит один раз показать юристу.

## Бесплатные лимиты Cloudflare
100 000 запросов в день, KV: 1 000 записей и 100 000 чтений в день. Подписки хранятся
в метаданных ключей, поэтому ежедневная рассылка не тратит чтения. Хватит на тысячи пользователей.
